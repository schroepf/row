# Triage Labels

This repo uses the default triage labels for the `triage` skill:

| Label               | Purpose                                                                 |
|---------------------|-------------------------------------------------------------------------|
| `needs-triage`      | New issue; needs categorization.                                        |
| `needs-info`        | Requires clarification from the reporter.                               |
| `ready-for-agent`   | Ready for an agent to implement or investigate.                         |
| `ready-for-human`   | Ready for a human to review or implement.                               |
| `wontfix`           | Will not be addressed (e.g., invalid, duplicate, or out of scope).      |
